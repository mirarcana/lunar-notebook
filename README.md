# Лунный блокнот

Мой учебный проект на Django. Для локального запуска понадобятся Python 3.12 и копия этого проекта. Базу данных (я оставила SQLite) Django создаёт при первом запуске миграций. Через gitignore убрала свою копию БД и всего ненужного для гита.

## Установка

Клонируйте репозиторий через Git. Откройте терминал (или проект в ide) в папке с файлом `manage.py`.

Создайте виртуальное окружение, активируйте его, установите зависимости, запустите миграции и запускайте сервер:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
Откройте http://127.0.0.1:8000/ в браузере.
