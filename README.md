# Лунный блокнот

Мой учебный проект на Django. Для локального запуска понадобятся Python 3.12 и копия этого проекта. Базу данных (я оставила SQLite) Django создаёт при первом запуске миграций. Через gitignore убрала свою копию БД и всего ненужного для гита.

## Установка

Клонируйте репозиторий через Git. Откройте терминал (или проект в ide) в папке с файлом `manage.py`.

Создайте виртуальное окружение, активируйте его, установите зависимости, запустите миграции и запускайте сервер:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
Откройте http://127.0.0.1:8000/ в браузере.

## Страницы блога

- `/` - главная со ссылкой на заметку.
- `/about/` - о блоге.
- `/posts/earthrise/` - заметка о фотографии с лунной орбиты.
- `/reviews/` - книга отзывов и форма для посетителей.

Фото хранится в статических файлах приложения.

## Проверка отзывов

1. Запустите `python manage.py createsuperuser`. Задайте имя и пароль администратора.
2. Отправьте отзыв со страницы `/reviews/`.
3. Войдите в `/admin/blog/review/`, откройте отзыв, поставьте галочку "Проверено" и сохраните.
4. Обновите `/reviews/`. На странице появятся ФИО и текст. Адрес электронной почты доступен только в панели администратора.
